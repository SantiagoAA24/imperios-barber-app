Encabezado de cada sección del flujo de agendamiento: un círculo con el número de paso y el título en `h2`.

**Quien lo usa aporta:** el número y el título (una o dos palabras, mayúscula solo en la primera).

**Clases:** `imp-step` con `imp-step__n` e `imp-step__title`.

- Número: círculo de 28 px, borde y texto `gold`. Título: `h2` en `display`.
- Va a `space-4` (14 px) del contenido de la sección; las secciones se separan con `space-6`.
- Usa el elemento `h2` real para que el lector de pantalla pueda saltar entre secciones.
