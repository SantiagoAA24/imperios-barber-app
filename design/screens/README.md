# Pantallas de referencia

Diseños de Imperio Barber exportados de Claude Design. Son **referencia visual y de contenido** (estructura, textos, espaciados, estados): no se importan en la app.

Cada archivo `.dc.html` es un componente de diseño con su marcado y estilos en línea. Para verlos renderizados hay que abrirlos en el canvas original de Claude Design; aquí se leen como código.

| Archivo | Pantalla | Área | Ancho |
| --- | --- | --- | --- |
| `agendar.dc.html` | Agendamiento en 3 pasos (dirección A, negro y dorado) | Cliente | 390 |
| `cita-confirmada.dc.html` | Cita confirmada | Cliente | 390 |
| `catalogo.dc.html` | Catálogo de productos | Cliente | 390 |
| `cliente-cancelar.dc.html` | Cancelar cita | Cliente | 390 |
| `barbero.dc.html` | Agenda del día | Barbero | 390 |
| `barbero-nueva.dc.html` | Nueva cita manual | Barbero | 390 |
| `barbero-horario.dc.html` | Mi horario | Barbero | 390 |
| `admin-resumen.dc.html` | Resumen | Admin | 1280 |
| `admin-agenda.dc.html` | Agenda por día | Admin | 1280 |
| `admin-semana.dc.html` | Agenda por semana | Admin | 1280 |
| `admin-servicios.dc.html` | Servicios | Admin | 1280 |
| `admin-productos.dc.html` | Productos | Admin | 1280 |
| `admin-barberos.dc.html` | Barberos | Admin | 1280 |
| `admin-clientes.dc.html` | Clientes | Admin | 1280 |

Notas: los datos de las pantallas son de ejemplo (nombres y cifras inventados). Las imágenes del sello apuntan a `../../design-system/assets/Logo/imperio-sello.png`. Las variantes de estilo descartadas (B vintage y C moderno) no se incluyen.
